# TinEye

**Category:** Image OSINT

**Purpose:** Reverse image search engine specialized in finding where an image has previously appeared online, including modified/cropped versions.

**Website:** [tineye.com](https://tineye.com)

**Status:** ✅ Active | **License:** Free tier + paid API

**Installation:**

No installation required — web-based. A browser extension and API are also available.

**Basic Usage:**

Upload an image or paste an image URL at [tineye.com](https://tineye.com).

**What it is useful for:**

- Finding the earliest known appearance of an image (useful for verifying if a photo is original or recycled).
- Detecting image reuse, including cropped or edited versions.
- Fact-checking and verification workflows for journalism and investigations.

**Limitations:**

- Coverage depends on TinEye's own index — it will not find images it hasn't crawled.
- Works best on distinctive images; near-identical stock photos can produce noisy results.
- Free tier has search limits.

**Operational Safety:**

Uploading an image sends it to TinEye's servers — avoid uploading sensitive or confidential images unless you've reviewed their privacy policy. Prefer searching by URL when the image is already public.
