# Search Engines for OSINT

General-purpose and specialized search engines, each with different indexing behavior, coverage, and operator syntax. Using more than one is often necessary — no single engine indexes everything.

## General-Purpose

| Engine | URL | Notes |
|---|---|---|
| Google | [google.com](https://www.google.com) | Largest general index; supports advanced operators (see [Google Dorking](../tools/search-engines/google-dorking.md)). |
| Bing | [bing.com](https://www.bing.com) | Different index than Google; occasionally surfaces content Google misses. |
| DuckDuckGo | [duckduckgo.com](https://duckduckgo.com) | Privacy-respecting, no query logging tied to an account. |
| Brave Search | [search.brave.com](https://search.brave.com) | Independent index, privacy-focused. |
| Yandex | [yandex.com](https://yandex.com) | Strong coverage of Russian/CIS-region content; see also [Yandex Images](../tools/images/yandex-images.md). |

## Specialized

| Engine | URL | Notes |
|---|---|---|
| Shodan | [shodan.io](https://www.shodan.io) | Internet-connected device/service search — see [tool page](../tools/domains/shodan.md). |
| Censys | [censys.com](https://censys.com) | Internet-wide scan/certificate search — see [tool page](../tools/domains/censys.md). |
| Ahmia | [ahmia.fi](https://ahmia.fi) | Filtered search engine for legitimate onion services — see [tool page](../tools/dark-web/ahmia.md). |
| crt.sh | [crt.sh](https://crt.sh) | Certificate Transparency log search — useful for subdomain discovery. |
| Wayback Machine | [web.archive.org](https://web.archive.org) | Historical snapshots of web pages; essential for verifying past content. |
