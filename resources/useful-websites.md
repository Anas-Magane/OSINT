# Useful Websites for OSINT

A short list of reputable, frequently used reference sites that complement the tools in this repository. These are official/authoritative sources, not tools with installation steps.

## Domain / Network Records

- **WHOIS / RDAP lookups** — registrar records for a domain. Use your registrar's or a neutral RDAP lookup service; avoid unofficial "WHOIS history" sites of unknown provenance.
- **[crt.sh](https://crt.sh)** — Certificate Transparency log search, useful for subdomain discovery.
- **[BGP.he.net](https://bgp.he.net)** — ASN, IP block, and routing information (Hurricane Electric).

## Breach & Exposure Checking

- **[haveibeenpwned.com](https://haveibeenpwned.com)** — see [tool page](../tools/breach-intelligence/haveibeenpwned.md).

## Threat Intelligence

- **[virustotal.com](https://www.virustotal.com)**, **[urlscan.io](https://urlscan.io)**, **[abuseipdb.com](https://www.abuseipdb.com)**, **[otx.alienvault.com](https://otx.alienvault.com)**, **[greynoise.io](https://www.greynoise.io)** — see the [Threat Intelligence](../tools/threat-intelligence/) category for full tool pages.

## Archival / Historical Reference

- **[web.archive.org](https://web.archive.org)** (Wayback Machine) — historical snapshots of web pages; critical for verifying what a page said in the past or recovering removed content.
- **[archive.today](https://archive.ph)** — on-demand page archiving, useful for preserving evidence with a timestamp.

## Legal / Ethical Reference

- Refer to your jurisdiction's data protection authority (e.g., a national DPA) for the current text of applicable privacy law before conducting research involving personal data.
