# Google Lens

**Category:** Image OSINT

**Purpose:** Visual search tool that identifies objects, text, locations, and visually similar images from an uploaded photo or image URL.

**Website:** [lens.google.com](https://lens.google.com)

**Status:** ✅ Active | **License:** Free (Google account not required for basic web use)

**Installation:**

No installation required — available at [lens.google.com](https://lens.google.com), inside the Google app (mobile), and integrated into Google Images.

**Basic Usage:**

Upload an image or paste an image URL, then review visually similar results, detected text, and matched landmarks/products.

**What it is useful for:**

- Identifying a location, landmark, product, or object shown in a photo.
- Finding visually similar images across the web as a starting point for image-origin research.
- Extracting and searching text embedded in an image.

**Limitations:**

- Not exhaustive — coverage depends on Google's indexing.
- Best suited to distinctive imagery (landmarks, logos, products); generic scenes produce weak matches.
- No official public API for this feature; it's designed for interactive/manual use.

**Operational Safety:**

Uploaded images are processed by Google — avoid submitting sensitive or confidential material. Use an account-free/incognito session if you don't want the search tied to a personal Google account.
