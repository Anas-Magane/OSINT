# OSINT Framework

**Category:** All-in-One

**Purpose:** A visual, categorized directory of OSINT resources and tools — not a tool itself, but a navigable map to find the right resource for a given data type (username, email, domain, image, etc.).

**Official Repository:** [github.com/lockfale/OSINT-Framework](https://github.com/lockfale/OSINT-Framework)

**Website:** [osintframework.com](https://osintframework.com)

**Status:** ✅ Active | **License:** MIT

**Installation:**

No installation required — browse at [osintframework.com](https://osintframework.com).

**Basic Usage:**

Click through the category tree (e.g., Username → Social Networks) to reach curated external tools and resources for that data type.

**What it is useful for:**

- Discovering additional specialized resources beyond this repository's curated list.
- Quickly orienting yourself on "what category of tool do I need for this data type."

**Limitations:**

- Being a large, community-maintained directory, some linked third-party resources may be outdated, moved, or discontinued — always verify a link before relying on it.
- Not curated to the same depth as the tool pages in this repository; treat it as a discovery map, not a vetted list.

**Operational Safety:**

The framework itself is just a link directory — safety considerations depend on whatever external tool you click through to. Apply the same [OPSEC](../../docs/opsec.md) and [Legal & Ethical Use](../../docs/legal-and-ethical-use.md) principles to any resource you reach from it.
