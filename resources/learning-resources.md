# Learning Resources

Curated references for going deeper into OSINT methodology and practice, beyond this repository.

## Guides & Frameworks

- **[Aramon OSINT Guide](../docs/OSINT_Guide_Aramon.pdf)** — the companion guide to this repository, maintained by Aramon Institute of IT.
- **[OSINT Framework](https://osintframework.com)** — categorized directory of external OSINT resources (see [tool page](../tools/all-in-one/osint-framework.md)).

## Communities & Practice

- **Bellingcat** ([bellingcat.com](https://www.bellingcat.com)) — open-source investigative journalism organization; publishes methodology write-ups and case studies widely respected in the OSINT community.
- **CTF platforms with OSINT categories** (e.g., TryHackMe, Hack The Box) — hands-on practice in legal, sandboxed environments.

## Foundational Skills

- Learn search engine operators thoroughly — see [Google Dorking](../tools/search-engines/google-dorking.md).
- Learn to read and interpret DNS/WHOIS records — foundational for the [domain/infrastructure](../tools/domains/) tools.
- Practice source verification and lateral reading (checking what other sources say about a source, not just what the source says about itself).

## Staying Current

OSINT tooling changes quickly — platforms patch detection methods, APIs get deprecated, and new tools emerge. Periodically revisit:

- This repository's [tool directory](../README.md#-tool-directory) for status updates.
- Official repositories/release notes for tools you rely on regularly.
